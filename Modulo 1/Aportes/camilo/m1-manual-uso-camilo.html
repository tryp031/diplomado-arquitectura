1Alcance

Qué cubre este manual.

Este manual asume que el sistema ya está instalado y arrancado: hay una terminal mostrando http://127.0.0.1:8080 (u otro puerto) y el navegador tiene esa dirección abierta. Cubre cómo operar la interfaz una vez que está en pantalla: qué hace cada botón, qué significa cada número, y qué esperar de una operación normal.

No cubre cómo instalar el sistema ni por qué está construido de una forma u otra — solo lo que se ve y se hace en esta pantalla. Los números que la interfaz muestra son para explorar el sistema, no el resultado oficial que se entrega.

Un límite real de esta interfaz, y por qué es correcto que exista: el navegador no es el instrumento de medición. El servidor que la atiende (app/servidor.py) vive en milisegundos; el reto se juega en microsegundos y nanosegundos. Por eso, cada vez que se manda un estímulo, la interfaz muestra dos números por separado — ver la sección 4 — en vez de uno solo que mezclaría ambos mundos.

3Encender y apagar variantes

Cada variante es una tarjeta independiente.

Arrancar todasParar todas

Cada variante aparece como una tarjeta con su nombre, su puerto y un botón. El botón dice Arrancar si está apagada y Parar si está encendida.

ACTIVO

TCP Python

:9101 · TCP_NODELAY · conexión persistente
Parar
PARADO

Memoria compartida C

:9103 · espera activa · cero llamadas al sistema
Arrancar
  • Arrancar una variante ya arrancada no falla: la interfaz avisa «ya estaba corriendo» y no hace nada más.
  • PENDIENTE no es «esta máquina no puede correr esta variante» — es «faltan sus archivos en esta copia del proyecto» (por ejemplo, una carpeta que no se descomprimió completa). En ese estado la tarjeta no tiene botón: no hay nada que arrancar.
  • Que falte el compilador de C es otra cosa y se ve distinto: la tarjeta de Memoria compartida C sigue en PARADO con su botón normal, y al hacer clic el aviso explica que falta make (sección 8) — típicamente Windows nativo sin WSL2, ver manual de instalación, sección 3.4.
  • Parar una variante corta también cualquier conexión abierta con ella (por ejemplo, la que usa «Probar clasificación»). La siguiente vez que se necesite, se vuelve a abrir sola.

Apagar el sistema completo no se hace desde el navegador: se hace con Ctrl+C en la terminal donde se ejecutó el arranque. Al hacerlo, el propio servidor de control para las variantes que haya dejado encendidas, para no dejar procesos huérfanos.

4Probar clasificación

Un estímulo suelto, con el veredicto y los dos relojes por separado.

Esta sección manda un estímulo suelto y muestra el veredicto. Funciona contra cualquier variante que esté arrancada: a la que acepta conexiones de red se le habla por un socket; a la que no (memoria compartida) se le habla lanzando su propio cliente una vez, con el estímulo como argumento. Desde la interfaz no se nota la diferencia — las dos responden igual.

El campo «Host a clasificar» ofrece los hosts de la tabla, sin agrupar por LOCAL o EXTERNO (a propósito: la interfaz no adelanta la clasificación antes de preguntarle al sistema), y una opción «Otro host o IP» para escribir a mano uno que no esté en la tabla — sirve para comprobar que lo no clasificado responde DESCONOCIDO.

Al enviar, la respuesta muestra el veredicto y, debajo, dos medidas por separado, nunca una mezclada con la otra — ejemplo real contra core-bancario en WSL2:

El sistema623,3 µs reloj monótono alrededor del intercambio real · frontera F1
Desde el navegador3,38 ms incluye HTTP, JSON, React y el bucle de eventos

La web añadió ≈5× en este ejemplo. No son los números del informe oficial (ver sección 1) y varían de una corrida a otra — sobre todo el primer estímulo después de arrancar, más lento que los siguientes.

Ese número — cuántas veces más tardó el navegador que el sistema — es la demostración, dentro de la propia interfaz, de por qué el navegador no puede ser el instrumento de medición.

qué cambia la variante

La variante no cambia el veredicto: cambia cuánto tarda en darlo. Lo que no esté en la tabla responde DESCONOCIDO — es la política por defecto, lo no clasificado explícitamente se rechaza.

El sello «✓ Cumple» se evalúa contra el p99,9, no contra la mediana ni el promedio. Con solo 3 000 muestras los percentiles altos caen en muy pocas observaciones de la cola — es el motivo por el que el informe oficial usa 1 000 000 de iteraciones y no un atajo corto como este.

por qué memoria-compartida-c no admite clientes concurrentes

Memoria compartida C no tiene conexiones que aceptar: cliente y servidor comparten una única región de memoria con una sola ranura por sentido. Dos clientes a la vez se pisarían el payload y podrían leer la respuesta del otro. Cada proceso además gira ocupando un núcleo entero, así que 8 clientes + 8 servidores pelearían por 10 núcleos.

No es una limitación de implementación: los 83 ns de referencia se pagan con exclusividad.

6Historial y CSV

Cada estímulo mandado desde la sección 4 queda registrado aquí.

Descargar CSVLimpiar

Cada estímulo mandado desde «Probar clasificación» (sección 4) queda como una fila en esta tabla: número, hora de inicio, hora de fin, variante, host y las dos medidas de tiempo de la sección 4. Guarda hasta 500 entradas y sobrevive a recargar la página (F5) porque el historial vive en el servidor, no en el navegador — se pierde al apagar el sistema.

La tabla no tiene columna de veredicto. Es a propósito, el mismo criterio que retiró el editor de la tabla de hosts: mostrar aquí el LOCAL/EXTERNO de cada fila iría reconstruyendo la lista de clasificación fuera de línea. Una fila fallida se marca con ⚠ junto al host — el motivo del fallo aparece al pasar el cursor por encima.

Descargar CSV exporta lo que se ve en pantalla (respeta el filtro de variante, si está activo) a un archivo para abrir en Excel o Sheets: número, fecha, hora de inicio, hora de fin, variante, host, IP, web_ms y sistema_us. Tampoco tiene veredicto — mismo criterio que la tabla en pantalla. La columna con la medida oficial es sistema_us (microsegundos, con dos decimales para que no desaparezca la cifra de Memoria compartida C); web_ms es solo el contraste del navegador.

Limpiar vacía el historial del servidor — no se puede deshacer; si se necesitan los datos, descargar el CSV antes.

7Qué es normal ver

Referencia rápida, no diagnóstico de instalación.

A diferencia del diagnóstico del manual de instalación, sección 5 (que revisa si el sistema arrancó), esto es qué esperar mientras se usa ya arrancado:

Se veEs normal cuando…
«El sistema» tarda más en el primer estímulo que en los siguientesPara la variante con socket, la primera conexión paga el handshake TCP. Para Memoria compartida C, todos los estímulos sueltos son «en frío» (arranca un proceso nuevo cada vez) — no solo el primero

El puerto 9101 ya está ocupado…Un servidor de una sesión anterior quedó escuchandoEl propio aviso trae el comando para liberarlo, según el sistema

Ninguno de estos mensajes indica un problema del plano de datos: todos ocurren antes de llegar a él, en la validación del servidor de control. Si el síntoma es distinto — por ejemplo, la interfaz no carga — es un problema de instalación, no de uso: ver el manual de instalación, sección 6.
